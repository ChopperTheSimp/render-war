クイズ袋
■ 概要

本プロジェクトは、基本的なWebアプリケーションの機能を実装したものです。
ユーザー操作に応じてデータを処理し、画面上に結果を表示するシンプルなシステムとなっています。
内容は　日本の知識についてのクイズをユーザーに答えて貰って　３問当たったらご褒美として　
QRコードあげます。それを使って　モールまたはコンビニで　レジ袋と交換できるていうアプリです。
実際に交換できるまでは行けませんでしたが、QRコードを表示するまで行けました。
(管理者としてログインして触ってみちください。UserNmaeは　adminで　パスワードは自由です。)
現時点ではデータ保存にローカルのテキストファイルを使用しており、基本的な機能の動作確認が可能です。
Render でもデプロイしてますが、テキストデータベースのため毎回再展開するとデータ消えました。そのため、
今はPostgre データベースに切り替えてます。
